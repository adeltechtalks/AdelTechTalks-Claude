# 🤖 Agents · The Content Machine

[← All skills](../README.md)

Skills do one job each. **Agents** chain them together and walk the flow with you — the **Content Machine** is the agent that runs the Content Creation OS end to end.

> [!IMPORTANT]
> **The agent suggests, you decide.** Nothing is published, sent or deleted without your approval.

## Agent map

| Step | The agent does | You do |
|:--|:--|:--|
| **Capture** | Turns your voice note into text, writes a clear title, creates the idea card | Speak or share |
| **Idea Gate** | Suggests answers to the four questions and checks if it's trending | Go · Park · Kill |
| **Research & Reference** | Finds videos on the same idea — what worked, what's missing | Pick the references |
| **Brief** | Suggests pillar, content type, AI angle and channel plan | Approve or edit |
| **Hook & Script** | Writes 3 hooks and a script draft in your voice | Choose and make it yours |
| **Shot List** | Generates the shot list for the content type | Review and add |
| **Setup & Gear** | Suggests the gear recipe from your Studio Profile | Confirm |
| **Footage Ingest** | Creates the project folder and names the files | Move the footage |
| **Edit** | Writes the edit plan and captions, pulls from your post-production kit | Final edit |
| **Publish Gate** | Checks links, disclosure, safe zones and licenses automatically | Approve or back to edit |
| **Package & Publish** | Captions, hashtags and schedule for every platform | Approve publishing |
| **Engage** | Groups repeated questions and turns them into ideas | Reply to people |
| **Analyze** | Pulls the numbers and suggests the lesson | Write the lesson |
| **Inventory** | 10 ideas per product, reminders for return and renewal dates | Keep · Return · Sell |

## Studio Profile

On first run, the agent asks once for your **Studio Profile** — the context every skill reads:

- Niche and pillars
- Gear: cameras, mics, lights
- Shooting locations
- Apps and licenses
- Platforms and goals
- Hours available per day

## Status

The Content Machine is **in design**. It will ship as a Claude Code agent and as part of [Content Creation OS Pro](../course/). The free skills in this repo are its building blocks — each one works on its own today.
