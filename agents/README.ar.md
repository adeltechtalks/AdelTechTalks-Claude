# 🤖 Agents · الـ Content Machine

[← كل الـ Skills](../README.ar.md)

<div dir="rtl">

كل Skill بتعمل حاجة واحدة. الـ **Agents** بتربط الـ Skills ببعض وبتمشي معاك في الـ Flow كله، والـ **Content Machine** هو الـ Agent اللي بيشغّل الـ Content Creation OS من أوله لآخره.

> ⚠️ **الـ Agent يقترح، وإنت تقرر.** مفيش حاجة بتتنشر أو بتتبعت أو بتتمسح من غير موافقتك.

## الـ Agent Map

| الخطوة | الـ Agent بيعمل | إنت بتعمل |
|:--|:--|:--|
| **Capture** | يحوّل الصوت لنص، ويكتب عنوان واضح، ويعمل Idea card | تتكلم أو تعمل Share |
| **Idea Gate** | يقترح إجابات الأسئلة الأربعة، ويشوف الموضوع Trending ولا لأ | Go أو Park أو Kill |
| **Research & Reference** | يدوّر على Videos بنفس الفكرة، ويقول عجبه إيه وناقصها إيه | تختار الـ References |
| **Brief** | يقترح الـ Pillar ونوع المحتوى والـ AI Angle وخطة المنصات | توافق أو تعدّل |
| **Hook & Script** | يكتب 3 Hooks ومسودة Script بصوتك | تختار وتعدّل بطريقتك |
| **Shot List** | يطلّع الـ Shot List على حسب نوع المحتوى | تراجع وتزوّد |
| **Setup & Gear** | يقترح المعدات من الـ Studio Profile بتاعك | تأكد |
| **Footage Ingest** | يعمل الـ Project folder ويسمّي الملفات | تنقل الـ Footage |
| **Edit** | يكتب الـ Edit plan والـ Captions، ويسحب من الـ Post-production kit | الـ Edit النهائي |
| **Publish Gate** | يعمل Check أوتوماتيك على اللينكات والـ Disclosure والـ Safe zone والـ Licenses | Approve أو Back to edit |
| **Package & Publish** | Caption و Hashtags ومواعيد لكل منصة | توافق على النشر |
| **Engage** | يلم الأسئلة المتكررة ويحوّلها أفكار | ترد على الناس |
| **Analyze** | يجيب الأرقام ويقترح الدرس | تكتب الدرس |
| **Inventory** | 10 أفكار لكل منتج، ويفكرك بميعاد الترجيع والتجديد | Keep أو Return أو Sell |

## الـ Studio Profile

أول مرة، الـ Agent بيسألك مرة واحدة عن الـ **Studio Profile**، وده اللي كل الـ Skills بتقرا منه:

- المجالات والـ Pillars
- المعدات: الكاميرات والمايكات والإضاءة
- أماكن التصوير
- الـ Apps والـ Licenses
- المنصات والأهداف
- تقدر تطلع كام ساعة في اليوم

## الحالة

الـ Content Machine لسه **في مرحلة التصميم**. هينزل كـ Claude Code agent، وكجزء من [Content Creation OS Pro](../course/README.ar.md). والـ Free Skills اللي في الريبو ده هي الأجزاء اللي بيتبني منها، وكل واحدة فيها شغالة لوحدها من دلوقتي.
